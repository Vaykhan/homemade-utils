### homemade-utils
This is a small project of mine to rewrite any Unix, GNU/Linux, BSD util in whatever way i(or contributors) can. Any kind of (cluttered, kinda awful, maybe professional, simple) code is accepted, feel free to contribute as long as it works.
### Guidelines
Create `self[toolname]` folder, and go on with your way. or Improve existing code!
